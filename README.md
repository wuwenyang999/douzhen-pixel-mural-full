# 豆阵｜原创拼豆工程图纸网站

网页端 MVP：展示原创巨幅拼豆壁画和立体拼豆包图纸；用户在外部虚拟商品渠道付款取得兑换码，再在本网站兑换和使用图纸。

## 本地运行

```bash
cp .env.example .env.local
npm install
npm run dev -- --port 3100
```

打开 `http://127.0.0.1:3100`。

首次用 `ADMIN_EMAIL` 对应邮箱注册后，该账户会获得 `/admin` 权限。请在上线前把 `SESSION_SECRET` 改为长随机字符串。

## 发码交付流程

1. 管理员登录 `/admin`，选择图纸并按批次生成兑换码（每个码 16 字节 / 128 位随机熵，形如 `PB-XXXX`）。
2. 明文码只在生成当次返回，立即复制并导入外部虚拟商品自动发货渠道；数据库只保存 SHA-256 哈希。
3. 买家付款后获得一个图纸专属兑换码。
4. 买家在本站注册并前往 `/redeem` 兑换；后端在单个数据库事务内同时把码标记为已用、把图纸永久绑定到账户。兑换接口带限流，连续失败会临时锁定以防试码。
5. 管理员可在 `/admin` 按批次查看码状态、作废未使用的码、为指定账户人工补发，并在审计表看到全部操作记录。

兑换码单次使用、绑定具体图纸版本；已用、作废或不存在的码都无法解锁。不要把本地 `data/pixel-mural.sqlite` 交给他人。

## 图纸与账户

- 图纸按「作品 slug + 版本号」不可变发布：色卡（MARD 291）、全图总颗数、总板数、成品尺寸、每个分区的逐格色号与每色「全图 / 当前分区」数量都在发布时固化；改色会发布新版本，已购用户仍可读取自己购买的那一版。
- 制作台 `/studio/[slug]` 与进度保存接口都同时校验「登录用户 + 已购权益」，未购或未登录无法读取逐格图纸。
- 密码只存 bcrypt 哈希，登录态用 HttpOnly 的 `pixel_mural_session` 会话；用户可在「我的图纸」注销账户，注销后清空邮箱与密码、旧会话立即失效，仅保留匿名化的兑换审计以防兑换码被重复使用。
- 隐私说明见 `/privacy`：只收集账户与图纸服务所必需的信息，不收集地址、身份证件或支付资料。

## 上线部署

这是带账号和兑换码的 Node 网站，不能部署为纯静态网站。选择支持 Node.js 和持久化磁盘的服务器或托管服务，并设置：

```text
ADMIN_EMAIL=你的管理员邮箱
SESSION_SECRET=长随机字符串
DATABASE_PATH=/持久化磁盘/pixel-mural.sqlite
PURCHASE_BASE_URL=你的外部虚拟商品购买页
```

部署命令：

```bash
npm install
npm run build
npm start
```

外部购买页由你配置的虚拟商品渠道承担收款和自动发码；本网站不保存任何支付信息。
