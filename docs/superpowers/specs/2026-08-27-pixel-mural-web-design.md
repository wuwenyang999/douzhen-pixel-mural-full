# 原创拼豆工程图纸网站：首版设计

## 目标

建设一个网页端图纸交付网站，销售原创超大型拼豆壁画和立体拼豆包图纸。网站不提供通用图片转图纸服务，不接入站内支付，也不承接小红书等外部平台运营。

首版以“外部虚拟商品收款 + 网站兑换码解锁”完成闭环：用户在外部合规的虚拟商品渠道付款并获得兑换码，回到网站兑换后，在账户内使用已购图纸。

## 用户与核心价值

面向愿意完成大型、复杂拼豆作品的年轻人。网站卖的是独家原创作品和完成作品所需的工程化交付，而不是像素化工具。

每件图纸需让用户清楚知道：成品是什么样、需要多少块板、尺寸多大、从哪一块开始做、需要哪些颜色、制作进度到哪里。

## 首版范围

### 图纸内容

- 原创超大型壁画：东方神兽、山河巨幅、赛博国风和原创像素史诗。
- 立体拼豆包：手机包、Y2K 小方包和原创游戏风斜挎小包。
- 使用演示用的原创示例数据和作品视觉，不使用未授权动漫或游戏 IP。

### 用户端页面

1. 首页：品牌价值、两条产品线、精选作品、制作方式与兑换入口。
2. 图纸库：按“巨幅壁画”和“立体潮玩”筛选，显示尺寸、拼板数、难度、价格和版权标签。
3. 图纸详情：展示作品、成品尺寸、颜色数、拼板数、预计豆数、交付清单和购买入口。
4. 兑换页：用户登录后输入单次兑换码；成功后将指定图纸写入“我的图纸”。
5. 我的图纸：列出已解锁作品与完成进度。
6. 在线制作台：查看总览和分区图，按拼板/组件定位并勾选完成；立体包额外显示组件与组装顺序。

### 管理能力

- 管理示例图纸、作品类型、结构数据和预览图。
- 为指定图纸批量生成兑换码、查看兑换状态、作废未使用码。
- 兑换码只存储哈希值；每个码绑定一个图纸、仅能兑换一次。

## 站外收款方案

网站的“购买”按钮跳转到外部虚拟商品渠道。渠道负责收款和把预先生成的专属兑换码发给买家；网站不处理支付信息。

运营流程：

1. 在网站后台为每个图纸批量生成单品兑换码。
2. 将对应图纸的一批兑换码导入外部虚拟商品自动发货渠道。
3. 买家付款后获得该图纸的兑换码。
4. 买家登录网站兑换，网站将图纸永久绑定至账户。

退款、补码和外部渠道订单对账由运营方在外部渠道处理。首版不做购物车、优惠券、会员订阅和站内退款。

## 数据与权限

最小数据模型：

- `Pattern`：标题、类型、介绍、价格、原创版权说明、预览、规格、总览、分区/组件。
- `PatternSection`：编号、名称、网格或组件说明、预览、制作指引。
- `RedemptionCode`：图纸 ID、码哈希、状态、兑换账户、兑换时间、作废时间。
- `User`：账户基本信息。
- `UserPattern`：用户已购图纸、已完成分区、最后访问时间。

所有图纸内容均在鉴权后的制作台读取。公开页只显示加水印预览和规格说明。在线查看不等于绝对防复制，但通过账户绑定、订单水印、后续更新和制作进度提供持续价值。

## 体验与视觉方向

风格为深色展览感与高饱和像素色块的结合：作品视觉为主，信息层级清晰。巨幅壁画突出“上墙效果”，立体包突出“拆解结构与可背成品”。

移动端优先保证浏览、兑换和分区定位可用；复杂编辑和后台操作以桌面端为主。

## 非目标

- 不复制其他拼豆网站的页面、代码、品牌或素材。
- 不做用户上传图片、AI 抠图、通用像素编辑器和品牌色号转换器。
- 不在首版接入微信支付、支付宝或银行卡信息。
- 不出售或展示未经授权的动漫、游戏、明星或其他第三方 IP 图纸。
- 不构建材料库存、物流或外部平台内容运营。

## 验收标准

1. 用户可以浏览两类图纸并查看完整规格。
2. 用户可以登录、输入有效兑换码并仅解锁该码绑定的图纸。
3. 已兑换图纸在“我的图纸”可见，制作台可按分区/组件查看并保存完成状态。
4. 已兑换、无效、作废或图纸不匹配的兑换码均不能重复解锁。
5. 管理端可以生成、查询和作废兑换码。
6. 网站在手机和桌面视口均能完成浏览、兑换和制作台定位。
